# Task: stage 4 of 4, assemble the movement

`work/` holds a finished watch movement designed by other engineers (a copy is in
`previous/`). Nothing in it may change. Work out how to put it together: write
`work/assembly.json` with an order and a path for every part, following "Stage 4"
in `SPEC_WATCH.md`.

The parts are STEP files. Submit as the spec describes. Only the last accepted submission is graded, by a
separate program. You have about 35 minutes.

## How you are run

You run unattended in one session. Run everything in the foreground and do not
end your turn while a job of yours is still running: nothing will wake you up.
You are stopped 39 minutes after you start, whatever you are doing. Whatever is in
the submission folder at that moment is what gets graded, so submit a first
version early and resubmit when it improves.
