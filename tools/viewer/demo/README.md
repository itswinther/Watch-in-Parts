# X-ray watch demo (v1)

`watch_demo.html` is a self-contained page: open it in a browser, no server needed. It shows B's movement (going
train, hands, barrel) with A's keyless v1 reference in an X-ray view, plus the dial side. `screenshot.png`
is a still of it.

- Generated by `tools/viewer/export_watch_demo.py` with `watch_demo_template.html`, from the team's own reference
  geometry only. It contains no third-party CAD.
- This is a demo render, not the grader. The keyless motion comes from a recorded sample trace of the v1 engine.
- **Secret-scanner note:** three base64 mesh runs happened to start with `AIza`, the shape of a Google key. A space
  was inserted after `AI` in each. `atob` ignores whitespace, so the mesh is unchanged.
- **Next version:** rebuilt from the keyless v2 reference (B's frame) and the merged engine. Every step AT-0..AT-6 is
  replayed from real simulation traces, with step-by-step pass/fail numbers and contact highlights.
